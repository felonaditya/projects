This project involves the design and simulation of a complete analog communication system using Python. It implements both Amplitude Modulation (AM) and Frequency Modulation (FM) schemes, covering the entire signal flow:

Message Signal → Modulator → Noisy Channel → Demodulator → Recovered Signal

The simulation demonstrates key concepts such as modulation/demodulation techniques (envelope detection, coherent detection, frequency discriminator), addition of Gaussian noise, and performance analysis through Signal-to-Noise Ratio (SNR).

All signals are visualized in both time and frequency domains with clear plots. The project also explores variants like DSB-SC, SSB, and VSB, and compares AM vs FM noise resilience and bandwidth utilization.
