Python - based ML project for credit card fraud detection :- analyzes imbalanced transaction data, handles class imbalance (e.g. SMOTE), trains ML classifiers and evaluates with AUC - ROC / recall.

Dataset link - https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud/

Research paper link - https://link.springer.com/article/10.1186/s40537-022-00573-8/
