Interactive Electromagnetic Wave Visualizer — A real-time physics demonstration that animates propagating electromagnetic waves with physically accurate sinusoidal motion, wavelength-dependent realistic colors (based on CIE 1931), and adaptive spatial scaling from nanometers to light-years. 

Built in both Python (Matplotlib) for desktop use and pure HTML5 Canvas + JavaScript for the web, it lets you instantly adjust the wavelength via an input box and see live updates for frequency, photon energy in eV, and a smooth animated wave with a glowing colored core.

Live demo: https://wavephysics.netlify.app/
