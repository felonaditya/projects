A comprehensive multi-language suite of Student Management Systems developed in Python, C, and C++, featuring secure admin authentication, robust file persistence, and full CRUD operations.

Python (GUI): A desktop application built with Tkinter featuring secure admin login, real-time search, CSV export, and comprehensive error handling.

C (Procedural): A file-persistent system supporting multi-subject marks tracking, advanced search, sorting, class statistics, and CSV export.

C++ (OOP): A console-based application utilizing dynamic mapping for unlimited subjects/grades, automated GPA calculation, advanced data filtering, and a robust input validation layer.
